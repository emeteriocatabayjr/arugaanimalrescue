# Project Instructions

## Project Shape
- This is a static, single-page website. The application lives in `index.html`; HTML, CSS, and JavaScript are inline.
- There is no package manager, build step, or automated test suite. Do not add a framework or build tooling for small changes.
- The page uses remote Google Fonts, Unsplash images, and an embedded Google Map. Browser checks that depend on these require an internet connection.

## Editing
- Keep changes focused and consistent with the existing HTML, CSS, and vanilla JavaScript style.
- The adoptable animal roster is the `petsData` array. Keep the filter values aligned with its `species`, `gender`, `size`, and `age` fields.
- Pet cards are generated by `renderPets`; filtering is handled by `filterPets`; adoption dialog behavior is handled by the modal functions. Update the relevant existing code rather than duplicating behavior.
- Preserve responsive behavior and semantic labels/alt text when changing the page.

## Verification
- Open `index.html` in a browser after changes. Check the initial pet list, species/gender/size/age filters (including no results), and opening/closing the adoption dialog when those areas are affected.
- Check a narrow viewport for layout overflow when changing styles or page structure.
- There are no repository-defined automated checks; do not claim tests passed unless an actual check was run.
